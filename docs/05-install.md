# Installing NØNOS Wallet on Android

Every release is published on the public repository
[NON-OS/shield-android](https://github.com/NON-OS/shield-android), and its README is the install
guide: which file to install, the SHA-256 check on Linux, macOS and Windows, the signer check,
installing, a copy from the NØNOS site, Obtainium, updating and removing.

The source of that README is [`public/README.md`](../public/README.md) in this repository. Each
release copies it there, with `scripts/check-release.sh` and the two files it needs, so a reader of
the public repository can check a release without this one. Change the guide here, never there.
