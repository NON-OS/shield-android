# NØNOS Wallet for Android v0.9.0

The first release on the production pool, for Android 9 or later on 64-bit ARM.

## What is new

- **The production pool.** Private transfers and withdrawals run on the NOX Shield production pool
  on Sepolia, `0xaEe51E82965Ec1DeD870F3f4c248Ad4AdDc3e1cb`. Every proof carries a not-before time,
  the ten-minute mark just passed, and is checked by the pool's own verifier.
- **Fees you see before proving.** A private transfer pays 0.0005 ETH or 400 NOX, a withdrawal
  0.50% of its amount, and either one adds the gas fee of whoever lands it: 0.0025 ETH or 2,000 NOX.
  Every figure is read from the pool's fee policy, and the pool is asked whether it takes the fee
  before the proof is made.
- **No relayer to trust.** A proof pays whoever submits it. The app hands it over Tor to the first
  of five landers that answers, each checked for the right pool first. None of them can change
  where the money goes. If none lands it within 30 minutes, you can settle it yourself.
- **A fresh address for every withdrawal**, filled in for you, and a warning when you type an
  address that has been used before.
- **The wait after a deposit.** A new note waits for 20 more notes and 6 hours, so the time of a
  deposit does not point at the spend. A meter shows what is left, and typing EARLY skips it.
- **Every failure in its own sentence**, the same on iPhone and Android.

## Before you install

This is a test release on a test network. Its tokens have no value, and nothing has been audited
yet. Use a fresh wallet, and write down its recovery words.

TESTING.md in this repository walks through installing, getting test funds, shielding, sending,
receiving and withdrawing.

Report a bug in Issues. Report a security problem through the Security tab, or to
ek@nonos.systems or team@nonos.systems.

## The files

- `NONOS-v0.9.0-test.apk`: install this one. It is the release build, signed with a test key. The
  first build signed with the release key will not install over it, so keep your recovery words
  and restore from them then.
- `NONOS-v0.9.0-unsigned.apk`: the same build before signing, aligned for 16 KB pages.
- A `.sha256` for each. Check the hash before installing.
